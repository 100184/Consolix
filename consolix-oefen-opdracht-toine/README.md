# AI Beleid Website 🤖

Professionele richtlijnen voor AI-gebruik: Do's & Don'ts.

## Overzicht
Moderne, responsive statische website (3+ pagina's) over ethisch en productief AI-gebruik in professionele context.

**Pagina's**:
- `main/html/index.html` - Home/Inleiding
- `main/html/dos.html` - Hoe AI WEL te gebruiken
- `main/html/donts.html` - Valkuilen vermijden

## Ontwerpkeuzes & Lessen
- **Structuur**: Semantisch HTML5, modulaire CSS/JS - geleerd van populaire sites (clean hierarchy zoals MDN/docs).
- **CSS**: Cleaner glassmorphism, Inter font, animaties/hovers voor engagement; mobiel-first (van Tailwind/Bootstrap inspiratie).
- **JS**: Lichtgewicht nav highlight (geen frameworks nodig).
- **Best Practices**: ARIA-ready, snelle laadtijd, accessibility (contrast/keyboard).
- **Lessen uit codebases**: Minimal dependencies (geen npm); utility-achtige CSS voor onderhoudbaarheid; vaste nav zoals SaaS sites.
